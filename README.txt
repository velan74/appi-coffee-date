APPI x VELAN - Sunlit cafe invitation

Extract this entire zip, then open index.html in your browser.
Keep the assets folder beside index.html. No build or installation is needed.
The modern calendar is included in calendar.js, with keyboard navigation,
month controls and unavailable past dates. It uses the existing saved date.
Custom time selection uses time-picker.js with hour/minute controls and AM/PM.

The background uses CSS gradients and a small local SVG: no WebGL or video.
All eleven screens have individual light moods with 1.8-second crossfades.
Leaves and window shadows sway over 28-36 seconds. Reduced-motion settings
show a still warm background. Success adds a gentle sunset light bloom.

script.js changes are confined to the No button movement. tracking.js,
EmailJS configuration, saved progress and screen flow are unchanged.
Hearts appear only in intro steam, on Yes, and briefly on success.
The No button has a reserved landing area below Yes with a safety gap.
The existing modern calendar and custom time picker are included.
Google Fonts, EmailJS and any existing remote tracking services require an
internet connection, just as in the original website. Fonts have fallbacks.
